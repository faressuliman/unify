# Unify - Reuniting Missing Persons with Their Families 🔍⛶

> A web-based platform designed to reconnect missing persons with their families using AI, identity verification, and authority oversight.

**Unify** is a graduation project that leverages cutting-edge technology to create a humanitarian platform for reuniting missing persons with their families. The system prioritizes security, scalability, and careful handling of sensitive data through advanced AI matching, identity verification, and administrative oversight.

---

## 📋 Project Overview

Unify addresses the critical need for missing person cases across Egypt and beyond by providing:

- **Real-time Integration**: Connect missing and found persons through AI-powered facial matching
- **Secure Identity Verification**: Multi-layer verification system with administrator oversight
- **Authority Coordination**: Ministry of Social Solidarity backed platform for official verification
- **Safe Communication**: Encrypted channels between verified parties to protect privacy
- **Interactive Tools**: Poster builder, live map, and advanced search capabilities

---

## ✨ Core Features

### For Public Users
- **Report Cases**: Post missing or found persons with image uploads
- **Image Search & AI Facial Matching**: Upload images to find similar cases using advanced AI facial matching algorithms that compare uploaded images against the entire database of registered persons
- **AI Fraud Detection**: All uploaded images (profiles, reports, IDs) are automatically scanned by an AI-powered fraud detector to identify and reject fake or AI-generated images, ensuring data authenticity
- **Advanced Search**: Search with filters and AI-powered matching capabilities
- **Submit Claims**: File claims with proof of relationship for verification
- **Poster Builder**: Generate PDF posters for distribution
- **Live Map View**: Real-time overview of active cases across Egypt
- **Notifications**: Stay updated on claim status and matches
- **Secure Chat**: Connect with verified parties after admin approval

### For Administrators/Authorities
- **ID Verification**: Verify user identities with document checks
- **Claim Review**: Review and approve/reject submitted claims
- **Report Moderation**: Moderate content and verify authenticity
- **AI Image Detection**: Comprehensive AI-powered system that detects and flags fake or AI-generated images before they enter the system
- **Case Management**: Comprehensive dashboard for managing reports

## 🏗️ Architecture

### Technology Stack

**Frontend:**
- React 19 + TypeScript + Vite
- Tailwind CSS v4 (utility-first styling)
- Framer Motion (animations)
- Radix UI primitives + shadcn/ui components
- React Leaflet (interactive maps)
- Lucide React (icons)

**Backend:**
- Node.js runtime
- MySQL database


**Internationalization:**
- Full bilingual support (English & Arabic)
- RTL/LTR layout support with logical CSS properties
